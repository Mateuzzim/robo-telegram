3 Acesso Local Mesmo WiFi

📍 Passo 1 - Abrir o terminal

No PC, abra o PowerShell ou CMD e navegue ate a pasta do projeto:

cd C:\Users\branc\Desktop\rob2\robotelegram

⚡ Passo 2 - Iniciar o servidor

Execute o comando para iniciar o relay:

node server.js

Vai aparecer algo assim:

================================================ SERVIDOR RELAY - ROBOTELEGRAM ================================================ PC: http://localhost:3000 Celular: http://192.168.1.105:3000 ------------------------------------------------

📱 Passo 3 - No celular

Abra o navegador no celular e digite o endereco que apareceu no terminal:

http://192.168.1.105:3000
⚠️
O numero do IP pode ser diferente. Use o que aparecer no terminal.

🖥️ Passo 4 - No PC (opcional)

Você também pode acessar pelo PC abrindo no navegador:

http://localhost:3000
4 Acesso Remoto Qualquer Lugar

📍 Passo 1 - Abrir 2 terminais

Abra dois terminais na pasta do projeto (pode ser duas janelas do PowerShell):

cd C:\Users\branc\Desktop\rob2\robotelegram

⚡ Passo 2 - Terminal 1: Iniciar o servidor

No primeiro terminal, inicie o relay:

node server.js

🌐 Passo 3 - Terminal 2: Iniciar o tunnel

No segundo terminal, inicie o tunnel para criar a URL publica:

node tunnel.js

Vai aparecer algo assim:

╔══════════════════════════════════════════════╗ ACESSO REMOTO ATIVADO ╠══════════════════════════════════════════════╣ URL PUBLICA: https://easy-bottles-raise.loca.lt ╠══════════════════════════════════════════════╣ Abra essa URL no celular de qualquer lugar ╚══════════════════════════════════════════════╝

📱 Passo 4 - No celular (de qualquer lugar)

Abra o navegador e digite a URL publica que apareceu:

https://easy-bottles-raise.loca.lt
💡
A URL muda a cada vez que voce reinicia o tunnel. Anote a URL atual.
🔴
Importante: Mantenha AMBOS os terminais abertos. Se fechar um, o sistema para.

8 Diagnostico de Problemas
Celular nao conecta no PC ▼
Verifique:
1. PC e celular estao no mesmo WiFi?
2. O firewall do PC esta bloqueando a porta 3000?
3. Tente desativar o firewall temporariamente
4. No Windows: painel de controle > firewall > regras > liberar porta 3000
URL do tunnel nao funciona ▼
Verifique:
1. O tunnel.js esta rodando?
2. O server.js esta rodando?
3. A URL expirou? (reinicie o tunnel)
4. Tente usar o endereco IP local em vez da URL publica
Dados nao aparecem em tempo real ▼
Verifique:
1. A VPN esta ligada no PC?
2. O relay esta conectado? (acesse /status)
3. Os tokens JWT nao expiraram?
4. Recarregue a pagina no celular (pull to refresh)
"Adicionar a tela inicial" nao aparece ▼
No Android: Use Chrome (nao outro navegador)
No iPhone: Use Safari (nao Chrome)
No PC: Use Chrome e acesse via HTTP (nao file://)
Dica: O endereco precisa ser HTTP/HTTPS, nao file://
Como parar o servidor? ▼
No terminal onde o server.js esta rodando:
Windows: Pressione Ctrl + C
Mac/Linux: Pressione Ctrl + C
Isso encerra o servidor e o tunnel automaticamente.
9 Dicas
💡
Iniciar automaticamente: Crie um atalho do server.js na area de trabalho e configure para rodar com node.
💡
Manter rodando: Use pm2 para manter o servidor rodando em background:
npm install -g pm2 && pm2 start server.js
💡
URL fixa no tunnel: Use um subdominio proprio:
lt --port 3000 --subdomain meuapp
URL: https://meuapp.loca.lt
💡
Verificar IP do PC: No PowerShell, execute:
ipconfig
Procure o endereco IPv4 under "Adaptador Wi-Fi".
